# 深見市聖杯戦争

「Fate」シリーズの聖杯戦争をモチーフにした、スマホ縦画面向けの個人用シミュレーションゲームです。
FGOに登場するサーヴァント131騎（基本7クラス114騎・エクストラクラス17騎）のデータを使い、架空の地方都市「深見市」で聖杯戦争を戦います。
（私的に楽しむためのファン制作物です。公開・配布はしない前提です）

## 遊び方

- `dist/index.html` をブラウザで開くだけで遊べます（インターネット接続があるとフォントがきれいに表示されます）。
- 進行は「行動選択画面」に戻るたびに自動保存されます（ブラウザの localStorage を使用）。

## 主人公の性別
最初の「運命」の画面で、主人公の性別（男性／女性／指定しない）を選べます。

- 自動で付く名前が、選んだ性別に合ったものになります（自分で入力した名前はそのまま）。
- 誕生の場面（「元気な女の子だった。」など）と、成長の章の名前（少年期／少女期／指定しないなら学童期）が変わります。
- ステータス画面に性別が表示されます。
- 物語の文章は、もともと主人公を「あなた」と呼ぶ書き方なので、どの性別でも違和感なく読めます。特別な関係（恋人など）も、性別に関係なく選べます。
- 「藤丸 立香」の特殊シナリオでも、選んだ性別が引き継がれます。

## ゲームの流れ（1プレイ約35分）

| 段階 | 内容 |
| --- | --- |
| 誕生（0歳） | 7種類の家（魔術の名門・ごく普通の家庭・教会の孤児院など）と、魔術属性・回路・生まれつきの得意がランダムに決まる |
| 生い立ち（3〜17歳） | 7回の節目ごとに「この数年をどう過ごすか」を選び、能力を育てる。その年頃の出来事が起き、幼馴染や不思議な老人との縁、触媒、属性が形作られる |
| 序章「令呪の冬」（18歳） | 右手に令呪が現れる。**参戦の経緯（下記）によって展開が変わる** |
| 召喚の夜 | 触媒があれば縁のある英霊を、なければ「育ってきたあなたの在り方」に似た英霊が応える |
| 第一幕「開幕」 | サーヴァントとの最初の朝、最初の敵、そして令呪を宿した幼馴染 |
| 第二幕「侵蝕」 | 昏睡事件、黒い影、聖杯の真実、泥に呑まれる陣営 |
| 第三幕「降臨」 | 決戦前夜、11日目以降の夜に天降山で決戦。真実を知っていれば「黒き聖杯」との戦いも |
| エンディング | 11種類（令呪を手放す「日常への帰還」を含む）＋幼馴染のその後 |

## 人生の転機（成長期のバリエーション）
産まれた時に、その家庭に合った「人生の転機」が一つ決まります（産まれごとに2種類、全14種）。成長に合わせて3つの章で進み、選択によってプラスにもマイナスにも転びます（`src/data_lifearcs.js`）。

| 産まれ | 人生の転機 |
|---|---|
| 魔術の名門 | **家督争い**（才能ある弟妹との後継争い：正々堂々競う／譲る／術式に細工する）・**政略の婚約**（許嫁との手紙、家の没落と婚約の行方） |
| 没落した家系 | **没落の真相**（家を陥れた名門の子との出会い、復讐か赦しか）・**母の病**（魔術の代償で倒れた母、禁術に手を出すか） |
| 時計塔の魔術師 | **派閥の渦**（貴族主義と民主主義、濡れ衣）・**天才の友**（禁忌に触れた友が封印指定に。匿うか、通報するか） |
| 魔術使いの傭兵 | **戦場の裏切り**（養父の相棒の裏切り、再会）・**拾った子**（紛争地で拾った子との暮らしと旅立ち） |
| 一般人 | **家族のかたち**（両親の離婚、どちらと暮らすか、和解か決別か）・**小さな妹**（妹の高熱の夜、魔術への目覚め） |
| 教会の孤児院 | **孤児院の闇**（地下の「代行者の養成」施設、告発か沈黙か）・**聖堂の光**（奇跡と信仰の揺らぎ、聖遺物） |
| 天降神社の跡取り | **神隠し**（山の神に連れ去られた従妹を取り戻す約束）・**神社の危機**（再開発をめぐって揺れる町） |

- 結末は「**人生の痕跡**」としてマスターのステータス画面に残り、序章のまとめ・エンディングにも書き添えられます。
- **聖杯戦争への影響**
  - 因縁の相手（弟妹・仇の家の子・封印指定の天才・裏切った養父の相棒）が、**敵のマスターとして参戦**します。関係が良ければ最初から同盟、悪ければ好戦的な敵に。3日目の夜には「因縁の再会」の場面があり、言葉を交わせば関係が変わることもあります。
  - 和解した両親からの仕送り、妹のお守り、家族として暮らす子の弁当、許嫁からの触媒、聖遺物の触媒など、準備期間に支援が届きます。
  - 孤児院の闇を告発すると教会に登録された状態で始まり、復讐心を抱くとアヴェンジャーの召喚条件にも関わります。

## 参戦の経緯（5つのルート）

18歳になった時点で、産まれ・成長中の選択・知った秘密の量によって、聖杯戦争への関わり方が決まります。

| ルート | 条件 | 序章の展開 |
| --- | --- | --- |
| 継承者 | 魔術の家に生まれ、家を継ぐ道を選んだ | 3日間の準備と召喚の儀。家の知識で召喚陣が一段階進んでいる |
| 請負人 | 傭兵として育った／教会の代行者の道を選んだ | 依頼・命令から始まる。前金・道具・敵情報、または教会の機密 |
| 探求者 | 一般の生まれだが、街の秘密を知り「真実を追う」道を選んだ | 自分の意思で参戦。召喚の方法を学ぶ師（老人・神社・独学・教会）を選ぶ |
| 巻き込まれた者 | 一般の生まれで、普通の人生を選んだ | 準備なし。ある夜、英霊同士の戦いを目撃して殺されかけ、令呪の光で英霊が応える。翌日、戦うか・令呪を手放すかを選ぶ |
| 背を向けた者 | 魔術の家に生まれたが、魔術から離れる道を選んだ | 令呪が現れた時、受け入れる（準備あり）か、拒む（いずれ巻き込まれる）かを選ぶ |

「街の秘密」は、幼い頃の熱の夢、天降山の黒い霧、河川敷の老人の昔話、目覚めた魔術回路などの出来事で少しずつ知っていきます。
17歳の「進路」で、知っている秘密が多いと「この街の秘密を追い続ける」という選択肢が現れます。

## 特殊シナリオ：藤丸 立香

名前を「藤丸　立香」（スペースの有無は問わない）にして始めると、特殊シナリオになります。

- FGOの物語を終え、日常に帰還した「元・人類最後のマスター」として、20歳の春から始まる
- 4月〜10月の7ヶ月（通常シナリオの成長期と同じ回数）を過ごして能力を育て、11月に令呪が現れる
- 基本ステータスはFGO準拠（魔術回路は平凡で魔力は低いが、精神・交渉・幸運が並外れて高い）。絆が深まりやすく、戦闘の指揮が巧み
- 歴戦のマスターなので、魔力が低くても英霊は十二分に力を振るえる（英霊パラメータに常にプラス補正）
- おおよその英霊を知っているため、対面した敵サーヴァントの真名を一目で看破する。敵の英霊が藤丸を覚えていることも
- 召喚した英霊は、かつてカルデアで喚ばれていた記憶を思い出す（再会の台詞・最初から高い絆・好みも把握済み・旅の思い出話）
- 英霊召喚の制限なし。英霊を指名して召喚できる（クラス別に全騎から選べる）
- マシュ・オベロン・アルトリア・キャスター・ダ・ヴィンチ・ネモなど、カルデアゆかりの英霊を召喚できる（通常シナリオでは召喚できない）
- 日常の中で夢に見た英霊を召喚すると「再会」となり、最初から絆が深い
- 時計塔の監視官、招待状の差出人「蒐集者」、聖杯戦争に仕組まれた陰謀を巡る専用の物語と、専用のエピローグ

### 藤丸専用の英霊：妖精王オベロン（`src/data_oberon.js`）
- **二つの人格**
  - **王子様**（人前で羽織るもの）：当たり障りなく、少しお調子者で、ひ弱で、努力家で、一歩引いて冷静。「いいとも！」と笑顔で快諾しておきながら、「素晴らしいと思うよ！ 不可能だって点を除けばね！」とノンデリなことも平気で言います。
  - **ヴォーティガーン**（本性に近いもの）：気だるく、面倒くさがりで、ぶっきらぼう。人間への嫌悪を隠しません。真顔と、シニカルな笑み。
- **藤丸に対して**：正体を知られているので、普段からややぶっきらぼうな「気心の知れた悪友」の距離感です。藤丸のことは買っていますが、人類は好みません。好意は滲ませず、本心も言いません（その心うちは本人にすら分かりません）。告白されても「好き」とは返さず、鼻で笑うことの方が多い苦労人です。
- 会話では、普段の悪友の口調に加えて、時々「人前用の王子様の顔」が出たり、マスターの様子（顔色・令呪の残り・眠れていない など）をぶっきらぼうに言い当てたりします。
- イベント「サーヴァントの夢」で奈落の夢を見て、そのことを話すと（または絆80以上で）、会話の後に時々、本性の声（紫の文字）が漏れるようになります。
- 関係イベント12種・エピローグの各章にオベロン専用の文面があり、共通の地の文で「照れたように笑った」などとなる所も、「鼻で笑った」など彼らしい反応に置き換わります。
- オベロン専用の会話イベント：「ブランカ」「王子様の外面」「素晴らしい作戦」「月を見上げる」（絆50以上・夜）。――決して明かされない、ただ一つの秘密がある。
- **躍動トリオ**：オベロンかアルトリア・キャスターと契約し、絆40以上になると、夜のイベント「躍動トリオ」（夢の中の三人の再会）が起きます。アルトリア・キャスターの思い出話にもオベロンが登場します。
- **エピローグ「レムレムの夢」**（5年後）：オベロンかアルトリア・キャスターと契約していた藤丸は、眠ると不思議な場所に繋がりやすい体質（カルデアでの通称「レムレム」）のせいで、夢の中の草原で三人が再会します。英霊と共に生きている人生か、別れた後の人生かで、会話の中身が変わります。

## 特殊シナリオ：衛宮 士郎
名前を「衛宮 士郎」（スペースの有無は問いません）にすると始まる、『Fate/stay night』の主人公のシナリオです。

> 冬木市の聖杯戦争から数年。胸に燻る「正義の味方」への憧れと共に、衛宮士郎は世界を周っていた。
> 遠坂凛からの連絡を受け、深見市の聖杯戦争へ。脳裏には、騎士王たる少女の姿が浮かんでいた。

- **世界を周った7年**（ロンドン・紛争地・砂漠の国・東欧の森・南の島・剣の丘・帰国の報せ）の過ごし方で能力を育てます。投影魔術、記憶の中のセイバーの剣筋、弓、遠坂からの魔術の授業、人助け、料理など。
- 旅立ちの朝の見送り（藤ねえ・桜・遠坂）、遠坂からの手紙、「天秤」の選択、赤い背中、心象風景「剣の丘」など、stay night の要素が随所に出てきます。主人公は男性になります。
- **召喚できるのはアルトリア（セイバー）だけ**。触媒は投影した「全て遠き理想郷（アヴァロン）」。月明かりの土蔵での、特別な召喚の場面があります。セイバーは主人公を「シロウ」と呼びます。
- 第五次聖杯戦争で見た英霊（クー・フーリン、メドゥーサ、メディア、佐々木小次郎、ヘラクレス）が敵として現れやすく、士郎は一目で正体に気付きます。敵のアーチャーは必ず「赤い外套の男」です。
  - 初めて剣を交える前には、原作での出来事や関係を踏まえた**専用の会話**が入ります（例：ランサーとは「心臓を貫かれた夜」とセイバーとの決着、ライダーとは桜の近況、キャスターとはセイバーの「衣装」、アサシンとは山門の石段、バーサーカーとはイリヤの面影、エミヤとは「正義の味方」への問い）。
- **マスターとしては未熟**（英霊のパラメータ補正-6）。その代わり、**戦闘では士郎自身の行動を選ぶのが中心**になり、セイバーは自分の判断で戦います（指示を出すこともできます）。

| 士郎の行動 | 効果 |
|---|---|
| 干将・莫耶で斬り込む | 士郎が直接攻撃・セイバー+6。ただし反撃を受けることがある |
| 弓で援護射撃 | 安全な援護・セイバー+4 |
| 熾天覆う七つの円環（ロー・アイアス） | オド20・その手番の敵の攻撃を大きく防ぐ |
| 偽・螺旋剣（カラドボルグII） | オド25・大ダメージ（士郎HP-5） |
| 是、射殺す百頭（ナインライブズ） | オド30・九連撃（士郎HP-10・1戦1回） |
| 無限の剣製（アンリミテッド・ブレイドワークス） | オド40・切り札。2手番目から（士郎HP-15・1戦1回） |
| セイバーと呼吸を合わせる | セイバー+8 |

- 道具（治癒の霊薬・宝石・魔力結晶）は、他のシナリオと同じく、行動選択の上の「道具」の欄で選び、士郎の行動と一緒に使います。

- 士郎のHPが尽きると、その戦闘では弓と援護しか使えなくなります。投影のために、オドの上限が高くなっています。

## マスターの魔術（系統を修め、研鑽する）
原作の「宝石魔術」「投影魔術」「ルーン魔術」「蝶魔術」のように、魔術は**系統（ジャンル）**ごとに修め、研鑽を重ねて深めていきます（`src/data_magecraft.js`）。

- **魔術の道**：マスターの魔力が **30 / 50 / 70 / 90** を超えるたびに出来事が起き、「新しい系統を修める（3つの候補から）」か「今の系統の研鑽に専念する」かを選びます。候補は産まれた家の系統に寄り、「家に伝わる」ものには印が付きます。
- **研鑽**：魔力が伸びるたびに研鑽が積み重なりますが、**修めた系統すべてに等しく分かれます**。一つに絞れば奥義まで極められ、複数を修めれば戦い方の幅は広がるものの一つあたりは浅くなります（一長一短）。昼の「マスターの鍛錬」→「**魔術の研鑽**」で、一つの系統を選んで集中的に深めることもできます。
- **研鑽の段階（Lv1〜5）**：戦闘の「マスターの行動」で使う技の名前と威力が変わり、Lv3とLv5（奥義）で新しい効果が加わります。系統によっては、日々の暮らしにも効果があります（宝石が溜まる、魔力結晶を精製する、使い魔が情報を拾ってくる、怪我が早く癒える など）。

## 封印指定執行者の襲来
魔術の系統を**奥義（研鑽Lv5）まで極める**と、その魔術は魔術協会に「封印指定」の対象として目を付けられます（衛宮士郎は「無限の剣製」を修めた時点で対象）。稀少な魔術を持つ魔術師を、その魔術ごと「標本」として保存するための制度です（`src/data_enforcer.js`）。

1. **警告**（聖杯戦争の昼）：時計塔からの封書（藤丸は監視官、岸波はムーンセル、士郎は遠坂からの電話）。どう備えるかを選びます。拠点の守りを固める、英霊と対策を練る、教会の仲裁、家の伝手、遠坂に頼む、監視官に掛け合う、ムーンセルで解析する など。備えるほど執行者は弱まります。
2. **襲来**（警告の二日後の夜）：封印指定執行者との戦い。執行者はサーヴァントではなく、**マスターを直接狙ってきます**。撤退はできず、**マスターのHPが尽きると「封印」**――標本として連れ去られます（エンディング「封印指定」）。守りの魔術、回避、霊薬が鍵になります。
3. **決着**：倒した執行者を「見逃す」（封印指定が取り消される）、「協会への伝言を託す」（戦利品を得る）、「とどめを刺す」（後々まで協会に追われる）。選んだ結末は、エンディングにも書き添えられます。

執行者は、プレイごとに3人の中から1人が現れます。

| 執行者 | 戦い方 | 切り札 |
|---|---|---|
| ヘルガ・ノイマン「鎖の執行者」 | ルーンを刻んだ千の鎖で縛り上げる | 封縛の鎖・千重（フェッセルン・タウゼント） |

## サーヴァントのスキル
全135騎に、FGOを参考元にした**保有スキル3種**と**クラススキル**があります（`src/data_skills.js`）。サーヴァントの画面と、真名が判明した敵の陣営の画面で確かめられます。

**保有スキル（戦闘中に使う）**：戦闘画面の「〇〇のスキル」の欄で選ぶと、その手番の行動と一緒に使います。1回の戦闘で各スキル1回まで。効果はスキル名とFGOでの役割から決めています（ランクが高いほど強い）。

| 効果 | 例 | 内容 |
|---|---|---|
| 白兵／機動／魔術強化 | 魔力放出・縮地・高速神言 | 3手番、その攻撃に補正 |
| 攻撃強化 | カリスマ・皇帝特権 | 3手番、すべての攻撃に補正 |
| 宝具強化 | 軍略・天才の証明 | 3手番、宝具に補正＋魔力 |
| 魔力充填 | 黄金律・吸血 | 魔力を回復 |
| 防御強化 | 守護の誓約・変化 | 3手番、受けるダメージを減らす |
| 回避 | 心眼・矢避けの加護 | 次の攻撃を1回無効に |
| 戦闘続行 | 戦闘続行・三度、落陽を迎えても | この戦闘中、一度だけHP0から踏みとどまる |
| 回復 | 仕切り直し・天性の肉体 | HPを回復 |
| 会心 | 病弱・霧夜の殺人 | 3手番、会心率が上がる |
| 弱体 | 原初のルーン・拷問技術 | 3手番、敵の判定を下げる |
| 行動封じ | 魔眼・愛の黒子・魅了 | 敵の次の手番を6割で封じる |
| 防御貫通 | 竜殺し・神殺し・直死の魔眼 | 3手番、敵の防御を貫く |
| 看破 | 直感・千里眼・啓示 | 敵の次の手を確実に読み、次の攻撃に補正 |

**クラススキル（常に働く）**：対魔力（敵の魔術戦を弱め、弱体・行動封じを防ぐ）／騎乗（機動戦+）／単独行動（毎日魔力回復）／陣地作成（迎撃+）／道具作成（毎日、霊薬を作ることがある）／気配遮断（奇襲・敵マスター狙い+）／狂化（攻撃+、被ダメージ+）／神性・女神の神核（攻撃+）／真名看破（対面した敵の真名を見抜く）／復讐者・忘却補正・自己回復（魔力）／領域外の生命。

敵のサーヴァントも自分のスキルを使ってきます（HPが減ると回復や戦闘続行を優先）。士郎シナリオでも、セイバーのスキルを士郎の行動と一緒に使えます。

## 関係ごとのイベント
特別な関係（恋人・無二の相棒・永遠の主従・家族）を結ぶと、その関係ならではのイベントが起きるようになります（各3種・計12種）。夜の「〇〇と語らう」で起きやすく、ランダムイベントとしても起きます。どれも結果として**能力値が大きく上がります**（1回でおよそ+12〜15）。

| 関係 | イベント |
|---|---|
| 恋人 | 二人だけの休日／月夜の約束／傷の手当て |
| 無二の相棒 | 連携訓練（宝具に合わせた連携を覚えると戦闘で毎手番+3）／無茶な作戦／勝利の祝杯 |
| 永遠の主従 | 主の器（英霊からの試練）／臣下の献上（生前の技を授かる）／令呪に誓う |
| 家族 | 家族の食卓／帰る場所（陣地Lv+1も）／看病 |

場面の描写は英霊の性格（高潔・王者・豪快・クール・温和・自由・影・学究・狂戦士）ごとに、台詞は話し方ごとに書き分けており、英霊の名前・宝具・願い・固有の台詞も織り込まれます。言葉を話さない英霊は、仕草で気持ちを伝えます（`src/data_bond_events.js`）。

## 聖杯の真相（2つのシナリオ）と調査
ゲームを始めた時点で、プレイヤーには見えない形で**聖杯の真相**が決まります（3つのうちどれか。どれも同じ確率）。

| 真相 | どんな戦争か | 昏睡事件の正体 |
|---|---|---|
| 呪われた聖杯 | 六十年前に「呪いそのもの」を呑んだ聖杯。願いは破滅の形で叶う | 聖杯から溢れた黒い泥 |
| 正規の聖杯 | 前回の儀式は器が満ちる前に途絶え、聖杯は無垢のまま眠っていた。願いは願ったとおりに叶う | ある陣営（犯人）の魂喰い |
| **人類悪、寄生** | 聖杯そのものは正しい。だが、器の底に人類悪・**ビーストⅧ「アダム=サーペント」**（理は【飽和】）が寄生し、六十年かけて魔力を吸い上げていた。最後の陣営を倒すと、空っぽの聖杯から姿を現し、ラスボスとして立ちはだかる。倒しても聖杯に魔力は残っておらず、**願いは叶えられない** | 獣の白い影。被害者は皆、幸せそうに微笑んだまま眠り続ける |

- 物語の見た目は、どちらでもほとんど同じです。**どちらなのかは、自分で調べない限り分かりません。**
- **昼の「真相を調べる」**で街の謎を調べます。場所ごとに「どの技能で調べるか」を選べます（例：事件現場を魔力で霊視する／知力で分析する／交渉で聞き込む／英霊に辿らせる）。
  - 大成功（目標を25以上上回る）でおまけの発見、大失敗（25以上下回る）で厄介ごと（正体の露見・負傷・教会の信用を失う など）。
  - 調べられる場所：昏睡事件の現場（2段階）・市民病院・天降神社の蔵・榊 宗玄の証言・教会の記録庫・天降山の霊脈（2段階）。事件現場と病院は4日目の「昏睡事件」以降。
- **夜の「事件現場に張り込む」**で、事件の瞬間を押さえられます（見張る／使い魔／囮になる）。
- **監督役に話を聞く**（調査の場所の一つ・1日1度）：何度か通うと、聖杯の器の様子を少しずつ教えてくれます。
  - 人類悪の場合、調査で得られる情報の多くは「正規の聖杯」に見えます（穢れはない、古文書も同じ）。ただし「被害者が幸せそうに眠っている」「六十年分にしては魔力が少なすぎる」などの小さな違和感が混ざります。
  - 監督役に**3回**話を聞くと「器の魔力が、外へ吸い出されている」と分かり、推理に第三の仮説**「聖杯に、何かが寄生している」**が加わります。人類悪の場合に「正規」と推理すると、噛み合わずに監督役を頼るよう促されます。
  - 岸波シナリオではムーンセルの解析でも気付けます。士郎シナリオの遠坂、藤丸シナリオの蒐集者の羊皮紙にも違和感が書かれています。
- 手に入れた手がかりは、マスターのステータス画面の**「調査手帳」**に残ります。同じ場所でも、真相によって見えるものが違うので、読み比べて推理できます。噂（真偽不明の情報）も混ざっています。
- 手がかりが**3**集まると「天降山の古社に潜入する」（危険な核心の調査）、**4**集まると「調査手帳を整理して推理する」（知力判定で仮説を確かめる）ができ、成功すると真相が確定します。
- 正規の聖杯だった場合、犯人の陣営を突き止めて教会に告発すると討伐令（令呪の報酬）が出ます。手口を知っていれば、犯人との戦いも有利になります。
- **結末への影響**
  - 呪いと知っている → 「聖杯を破壊する」で呪いとの最終戦へ。
  - 正規と知っている → 決戦前夜に「この聖杯になら、願いを託せる」を選べ、願いが正しく叶う。
  - 確かめていない → 疑いだけで聖杯を壊すこともできますが、正規の聖杯なら「砕かれた奇跡」になります。呪われた聖杯に知らずに願えば「歪んだ願い」です。
  - 人類悪の場合 → 最後の陣営を倒した後、ビーストⅧとの決戦になります（撤退不可）。正体を突き止めていれば「聖杯に巣食うものを、討とう」（決戦前夜）や正体看破の補正で有利に。知らないままだと、獣は最初の数手番、空の杯から魔力を吸い上げて回復します。勝てば「**楽園の外で**」（願いは叶わないが、眠っていた人々が目を覚ます）、負ければ「**飽和**」（街の人々が満ち足りた夢の中で眠り続ける）。

## 成長のしくみ

- 0歳の能力は「18歳の目安」の約3割。7回の過ごし方と出来事で伸ばしていく
- 家ごとに伸びやすい能力があり、生まれつきの得意（ランダム）はさらに伸びやすい（画面の「↑↑」）
- 魔術は魔術の家でしか学べない。一般人・孤児院育ちは12歳の「目覚め」から学べるようになる
- 幼い頃の選択（善・悪・秩序・混沌）が、召喚される英霊の傾向を決める
- 幼馴染との友情は、聖杯戦争で相手がマスターとして現れた時の展開（同盟・説得・決闘）を変える

## 主なしくみ

- **判定**：`能力値 + サイコロ(1〜45)` が目標値以上なら成功。結果は画面に数字付きで表示されます。
- **Fateのパラメータ**：ランク（E〜EX）を数値化（E=10、D=20 … A=50、EX=65、「+」1つにつき+5）して判定に使います。マスターの魔力が低いとサーヴァントの性能が下がります。
- **聖杯戦争中の行動（戦略）**
  - 昼：絆を深める／情報を集める（聞き込み・使い魔・文献・教会）／拠点を整える（結界・罠・霊脈）／買い出し／鍛錬／同盟交渉／休息
  - 夜：巡回（慎重 or 挑発）／偵察／襲撃（正面・奇襲・工房破壊・暗殺）／迎撃／語らい／休息（夜襲の危険あり）
  - 情報は「①マスター → ②拠点（襲撃可能） → ③真名（戦闘で有利）」の3段階
- **戦闘**：毎手番「マスターの行動」と「サーヴァントの行動」を1つずつ選びます。
  - サーヴァント：白兵・機動・魔術の三すくみ（白兵＞魔術＞機動＞白兵）、宝具、防御（防ぎ切ると反撃）、見切り（敵の次の手を確実に読む・真名の手がかり）、敵マスター狙い、令呪（4種の命令）、撤退
  - マスター：指揮／強化魔術／治癒魔術（オドを消費）／道具（霊薬・宝石・魔力結晶）
  - 敵の「構え」は知力が高いほど見抜ける。敵マスターも追い詰められると令呪を使う
- **属性と絆**：選択肢の「善・悪・秩序・混沌・慎重・大胆」でマスターの属性が変わり、サーヴァントの好みに合うと絆が上がります。
- **特別な関係**：絆Lv7以上で夜に語らうと、「恋人」「無二の相棒」「永遠の主従」「家族」から選べます。
- **絆の繋がり**：絆Lv7（絆70）以上になると「絆の繋がりが強くなった」状態になり、夜の「魔力を回復して休む」の回復量が上がります（魔力+30→+55、英霊のHP+15→+25、オド+10）。「恋人」は特別な関係の一つとして選べますが、子どもの英霊（ジャック・ナーサリー・アビゲイル・アンデルセン・武則天）とは選べません。この版には性的な描写はありません。

## サーヴァントの口調

英霊ごとに口調（14種）と一人称・二人称・呼びかけを設定しています（例：ネロ「余／そなた」、ギルガメッシュ「我／お前」、アストルフォ「ボク／キミ」、玉藻の前「ご主人様」、ジャック「おかあさん」）。
会話・告白・別れ・物語中の決まった場面の台詞は、すべて英霊の口調に合わせて言い回しが変わります。
さらに全134騎に固有台詞（絆の段階ごとの会話3つ・告白・別れ・藤丸シナリオの再会）を用意しており（`src/data_sig.js`）、会話やエンディングではこれが優先されます。
物語中の決まった場面（25場面：朝の問いかけ、黒い影からの警告、偵察、決戦前夜、消滅寸前など）の台詞も、言葉を話す128騎すべてに英霊ごとの台詞を用意しています（`src/data_say_1.js`〜`data_say_4.js`）。言葉を話さないバーサーカー6騎は行動の描写になります。
口調を変えたい英霊は `src/data_voices.js` の `VOICE_OF` を、台詞そのものを変えたい場合は `src/data_sig.js` の `SIG` を書き換えてください。
