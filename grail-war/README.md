# 深見市聖杯戦争

「Fate」シリーズの聖杯戦争をモチーフにした、スマホ縦画面向けの個人用シミュレーションゲームです。
FGOに登場するサーヴァント49騎のデータを使い、架空の地方都市「深見市」で聖杯戦争を戦います。
（私的に楽しむためのファン制作物です。公開・配布はしない前提です）

## 遊び方

- `dist/index.html` をブラウザで開くだけで遊べます（インターネット接続があるとフォントがきれいに表示されます）。
- 進行は「行動選択画面」に戻るたびに自動保存されます（ブラウザの localStorage を使用）。

## ゲームの流れ（1プレイ約30分）

| 段階 | 内容 |
| --- | --- |
| 産まれ | 7種類の産まれ（魔術の名門、一般人など）がランダムに決まり、能力値・資金・願い・初期道具が変わる |
| 序章（準備5日） | 能力を鍛え、触媒・道具を集め、召喚陣を整える。監督役や六十年前の生き残りと出会う |
| 召喚の夜 | 触媒があれば縁のある英霊を、なければ「マスターの属性に似た英霊」がランダムに応える |
| 第一幕「開幕」 | サーヴァントとの最初の朝、最初の敵との邂逅 |
| 第二幕「侵蝕」 | 昏睡事件、黒い影、聖杯の真実、泥に呑まれる陣営 |
| 第三幕「降臨」 | 決戦前夜（10日目の夜）、11日目以降の夜に天降山で決戦。真実を知っていれば「黒き聖杯」との戦いも |
| エンディング | 10種類（聖杯の破壊、受肉、願いを託す、歪んだ願い、脱落など） |

## 主なしくみ

- **判定**：`能力値 + サイコロ(1〜45)` が目標値以上なら成功。結果は画面に数字付きで表示されます。
- **Fateのパラメータ**：ランク（E〜EX）を数値化（E=10、D=20 … A=50、EX=65、「+」1つにつき+5）して判定に使います。マスターの魔力が低いとサーヴァントの性能が下がります。
- **聖杯戦争中の行動（戦略）**
  - 昼：絆を深める／情報を集める（聞き込み・使い魔・文献・教会）／拠点を整える（結界・罠・霊脈）／買い出し／鍛錬／同盟交渉／休息
  - 夜：巡回（慎重 or 挑発）／偵察／襲撃（正面・奇襲・工房破壊・暗殺）／迎撃／語らい／休息（夜襲の危険あり）
  - 情報は「①マスター → ②拠点（襲撃可能） → ③真名（戦闘で有利）」の3段階
- **戦闘**：毎手番「マスターの行動」と「サーヴァントの行動」を1つずつ選びます。
  - サーヴァント：白兵・機動・魔術の三すくみ（白兵＞魔術＞機動＞白兵）、宝具、防御（防ぎ切ると反撃）、見切り（敵の次の手を確実に読む・真名の手がかり）、敵マスター狙い、令呪（4種の命令）、撤退
  - マスター：指揮／強化魔術／治癒魔術（オドを消費）／道具（霊薬・宝石・魔力結晶）
  - 敵の「構え」は知力が高いほど見抜ける。敵マスターも追い詰められると令呪を使う
- **属性と絆**：選択肢の「善・悪・秩序・混沌・慎重・大胆」でマスターの属性が変わり、サーヴァントの好みに合うと絆が上がります。
- **特別な関係**：絆Lv7以上で夜に語らうと、「恋人」「無二の相棒」「永遠の主従」「家族」から選べます。

## 演出と設定

- 段落ごとに文章が現れる（表示中に画面をタップすると全文表示）
- 昼夜の切り替えカード、章の扉、時間帯で変わる空と雪
- 召喚陣が描かれ、光が弾け、クラスの紋章と真名が現れる召喚演出
- 宝具・令呪のカットイン、ダメージ数字、被弾時の揺れ、HPバーの減少アニメーション
- クラスごとの紋章と色、行動ボタンのアイコン、戦闘の三すくみ図
- タイトル画面の「設定」：文字送り（瞬時／普通／ゆっくり）、演出のON/OFF、効果音のON/OFF（初期はOFF）
- タイトル画面の「エンディング」：到達したエンディングの一覧（10種）

## ファイル構成（改造したい人向け）

```
grail-war/
├─ src/
│  ├─ data_servants.js  … サーヴァントのデータ（ステータス・宝具・触媒・召喚時の台詞）
│  ├─ data_world.js     … 舞台・産まれ・ライバル・性格ごとの台詞・特別な関係
│  ├─ data_story.js     … メインシナリオ（決まった日に起きる物語）・登場人物・隠しボス
│  ├─ data_events.js    … ランダムイベント（選択肢と結果）
│  ├─ fx.js             … 演出（設定・効果音・カットイン・雪・アイコン・エンディング記録）
│  ├─ core.js           … 状態・判定・時間の進行・イベント表示
│  ├─ actions.js        … 昼と夜の行動、召喚
│  ├─ battle.js         … 戦闘
│  ├─ ending.js         … 決戦・聖杯・エンディング
│  ├─ view.js           … 画面表示とタップ操作
│  └─ style.css         … 見た目
├─ build.py             … src をまとめて dist/ に1つのHTMLを作るスクリプト
└─ dist/
   ├─ index.html        … 遊ぶ用のファイル
   └─ artifact.html     … claude.ai のアーティファクト公開用
```

`src/` のファイルを書き換えたら、次のコマンドで `dist/` を作り直します。

```bash
python3 build.py
```

### サーヴァントを追加する例

`src/data_servants.js` の配列に1つ足すだけで、召喚・ライバルの両方に登場するようになります。

```js
{ id: 'example', name: '真名', short: '呼び名', cls: 'セイバー',
  p: ['B', 'C', 'A', 'D', 'B', 'A'],   // 筋力 耐久 敏捷 魔力 幸運 宝具
  align: '秩序・善', persona: 'knight',  // persona は data_world.js の PERSONAS から選ぶ
  np: '宝具名', npRuby: 'ルビ', catalyst: '触媒の名前',
  line: '召喚時の台詞', desc: '一行説明' },
```

### イベントを追加する例

`src/data_events.js` の `EVENTS` に足します（決まった日に必ず起こしたい物語は `src/data_story.js` の `STORY` へ）。`chk('int', 60)` で「知力判定・目標60」、`tone('good')` で善の行動、`bond(5)` で絆+5 になります。

## 注意

- サーヴァントのパラメータは記憶をもとにした目安で、公式設定と異なる場合があります。`data_servants.js` で自由に修正してください。
- 召喚時の台詞やイベントの文章はこのゲーム用に書き下ろしたものです。
