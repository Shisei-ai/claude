# 深見市聖杯戦争

「Fate」シリーズの聖杯戦争をモチーフにした、スマホ縦画面向けの個人用シミュレーションゲームです。
FGOに登場するサーヴァント49騎のデータを使い、架空の地方都市「深見市」で聖杯戦争を戦います。
（私的に楽しむためのファン制作物です。公開・配布はしない前提です）

## 遊び方

- `dist/index.html` をブラウザで開くだけで遊べます（インターネット接続があるとフォントがきれいに表示されます）。
- 進行は「行動選択画面」に戻るたびに自動保存されます（ブラウザの localStorage を使用）。

## ゲームの流れ

| 段階 | 内容 |
| --- | --- |
| 産まれ | 7種類の産まれ（魔術の名門、一般人など）がランダムに決まり、能力値・資金・願いが変わる |
| 準備期間（6日） | 昼・夜に1回ずつ行動。能力を鍛え、触媒を探し、召喚陣を整える |
| 召喚の夜 | 触媒があれば縁のある英霊を、なければ「マスターの属性に似た英霊」がランダムに応える |
| 聖杯戦争（最大14日） | 情報収集・絆・戦闘。残り1陣営になると天降山で最終決戦 |
| エンディング | 聖杯への願い方と、サーヴァントとの関係で8種類に分岐 |

## 主なしくみ

- **判定**：`能力値 + サイコロ(1〜45)` が目標値以上なら成功。結果は画面に数字付きで表示されます。
- **Fateのパラメータ**：筋力・耐久・敏捷・魔力・幸運・宝具のランク（E〜EX）を数値化（E=10、D=20 … A=50、EX=65、「+」1つにつき+5）して判定に使います。
- **マスター補正**：マスターの魔力が低いとサーヴァントの性能が下がり、高いと上がります（原作の設定に準拠）。
- **戦闘**：白兵（筋力）・機動（敏捷）・魔術（魔力）の三すくみ＋宝具＋令呪。クラス相性、真名看破、奇襲、陣地なども効きます。
- **属性と絆**：選択肢には「善・悪・秩序・混沌」などの傾向があり、マスターの属性が変化します。サーヴァントの属性と合う選択をすると絆が上がります。
- **特別な関係**：絆Lv7以上で夜に語らうと、「恋人」「無二の相棒」「永遠の主従」「家族」から関係を選べます。戦闘やエンディングに影響します。

## ファイル構成（改造したい人向け）

```
grail-war/
├─ src/
│  ├─ data_servants.js  … サーヴァントのデータ（ステータス・宝具・触媒・召喚時の台詞）
│  ├─ data_world.js     … 舞台・産まれ・ライバル・性格ごとの台詞・特別な関係
│  ├─ data_events.js    … ランダムイベント（選択肢と結果）
│  ├─ engine.js         … ゲームの進行・判定・戦闘・画面表示
│  └─ style.css         … 見た目
├─ build.py             … src をまとめて dist/ に1つのHTMLを作るスクリプト
└─ dist/
   ├─ index.html        … 遊ぶ用のファイル
   └─ artifact.html     … claude.ai のアーティファクト公開用
```

`src/` のファイルを書き換えたら、次のコマンドで `dist/` を作り直します。

```bash
python3 build.py
```

### サーヴァントを追加する例

`src/data_servants.js` の配列に1つ足すだけで、召喚・ライバルの両方に登場するようになります。

```js
{ id: 'example', name: '真名', short: '呼び名', cls: 'セイバー',
  p: ['B', 'C', 'A', 'D', 'B', 'A'],   // 筋力 耐久 敏捷 魔力 幸運 宝具
  align: '秩序・善', persona: 'knight',  // persona は data_world.js の PERSONAS から選ぶ
  np: '宝具名', npRuby: 'ルビ', catalyst: '触媒の名前',
  line: '召喚時の台詞', desc: '一行説明' },
```

### イベントを追加する例

`src/data_events.js` の `EVENTS` に足します。`chk('int', 60)` で「知力判定・目標60」、`tone('good')` で善の行動、`bond(5)` で絆+5 になります。

## 注意

- サーヴァントのパラメータは記憶をもとにした目安で、公式設定と異なる場合があります。`data_servants.js` で自由に修正してください。
- 召喚時の台詞やイベントの文章はこのゲーム用に書き下ろしたものです。
