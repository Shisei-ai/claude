# Descensus ad Inferos ── 賢者の石を求めて

冥界に囚われた妹レネイを救うため、錬金術師クラヴィスが森の奥の工房で【賢者の石】を創り出す、
ブラウザで遊べる魔法・錬金術の生産シミュレーションです。

## 遊び方

1. `index.html` をブラウザ(Chrome / Edge / Firefox など)で開くだけで遊べます。
   インストールやビルドは不要です。
2. 進行状況はブラウザの `localStorage` に10秒ごとに自動保存されます。

### ゲームの流れ

| 要素 | 内容 |
| --- | --- |
| **工房(工業)** | 設備を建造し、レシピを設定すると倉庫から自動で材料を取り出して作り続けます。探索中もページを閉じている間(最大4時間)も動きます。「在庫上限」を設定すると作りすぎを防げます。 |
| **探索** | フィールドで素材を採取し、魔物と戦います。自動生産できない素材はここでしか手に入りません。 |
| **戦闘** | 数字キー1〜6で割り当てた魔法を、マウスの方向へ放ちます。魔法は4段階の**グレード**（例: 火球→業火球→煉獄球→劫火）があり、上位グレードはそれを記した「魔術奥義書」を読むと習得します。 |
| **書庫** | 全ての術は**書物を読むことで習得**します。「Lvが上がる → 読める書物が増える → 読む → 記載された術（魔法とそのグレード・設備・レシピ・地域）を習得」という流れです。魔術書は M.Lv(戦闘で上昇)、錬金術書は A.Lv(生産で上昇)で読めるようになり、読むとSPも得られます。 |
| **技能** | SPを使って工業・探索・戦闘の3パネルから技能を習得します。 |

画面右の「いまの目標」に、次にやるべきことが常に表示されます。

### ホムンクルス（工業の補助NPC）

錬金術書『ホムンクルス生成論』（A.Lv 7）を読むと【培養の瓶】が建てられ、「ホムンクルス」タブが現れます。

- 【培養の瓶】で素材からホムンクルスを培養します（瓶1台につき3体まで養える）。名前が付いたNPCとして生まれます
- 設備に1体ずつ配置すると、その設備を補助します。働くほどレベルが上がり、効果が伸びます
- 働いている間は【培養液】を食べます。切らすと「空腹」になり効果が止まります

**個体値**：生まれた瞬間に4つの能力値（1〜20）が決まり、1体ずつ性能が違います。

| 能力値 | 影響 |
| --- | --- |
| 器用 | 本来の仕事の効果（×0.73〜×1.30） |
| 体力 | 培養液を食べる間隔（×0.83〜×1.40） |
| 知性 | 成長の早さ（×0.58〜×2.00） |
| 幸運 | 2倍生産の確率（+0.5%〜+10%） |

**レアリティ（抽選）**：生まれる瞬間に抽選で決まります。培養に「霊媒」を加えると上位が出やすくなります。
【秀】以上が100体続けて出なければ、次は必ず【秀】（天井。【極】は保証しない）。【極】はクリア後の書物『極めし人造生命』を読むまで出ません。
**ゲーム内では確率も天井も伏せています。** 画面には霊媒ごとの「言い伝え」だけが表示され、天井の8割（80体）を越えると
「培養の瓶が熱を帯び、底で何かが脈打っている」という兆しが現れます。下の表は開発用の実際の値です。

| レアリティ | 能力値 | 最大Lv | 固有スキル |
| --- | --- | --- | --- |
| 並 | 1〜12 | 10 | なし |
| 良 | 4〜15 | 15 | 1つ |
| 秀 | 8〜18 | 20 | 2つ |
| 極 | 12〜20 | 25 | 伝説スキル＋1つ |

| 霊媒（1回の量） | 並 | 良 | 秀 | 極 | 霊媒の作り方 |
| --- | --- | --- | --- | --- | --- |
| なし | 88% | 10% | 2% | ─ | ─ |
| 命の揺籃液 ×2 | 55% | 35% | 9% | 1% | 浄化の匣：生命の苔×3・草の精髄×5・聖水×3（『小人たちの手記』A.Lv10） |
| 月霊の結晶 ×2 | 15% | 50% | 30% | 5% | 魔化の匣：月長石×2・魔晶の欠片×5・魔素×8（『秀でし小人』A.Lv15） |
| 魂の萌芽 ×1 | ─ | 25% | 55% | 20% | 融合の釜：魂の残滓×8・妖精の鱗粉×3・第五元素×1（同上） |

新しい素材：**生命の苔**（芽吹き森でまれに採取）・**月長石**（霧深い鉱山でまれに採取）・**妖精の鱗粉**（永久雪原の雪の精が落とす）。
【極】が解放される前は、極の確率は【秀】に上乗せされます。

**秘薬（クリア後・『人造生命の秘奥』A.Lv18）**：生まれた後に能力値を変える、賢者の石を使う非常に高価な薬です。

| 秘薬 | 効果 | 素材（培養の瓶） |
| --- | --- | --- |
| 錬魂の秘薬 | 選んだ能力値1つを +3（最大20） | 賢者の石×1・第五元素×2・魂の萌芽×2 |
| 転生の秘薬 | 能力値4つをそのレアリティの範囲で振り直す（下がることもある） | 賢者の石×1・赤きティンクトゥラ×1・魂の萌芽×3 |
| 昇華の秘薬 | レアリティを1段階上げる（能力値の下限が上がり、スキルが増える） | 賢者の石×2・主の魂晶×2・魂の萌芽×5・原初の火種×5 |

**種類**：働き手（生産速度）・倹約（素材を消費しない確率）・豊穣（2倍生産の確率）・賢しき（A.Lv経験値）。
固有スキルには、配置した設備を強化するもののほか、工房全体の生産速度や全ホムンクルスの成長を上げるものもあります。
不要な個体は「瓶に還す」と、レアリティに応じた培養液が戻ります。

種類・能力値・レアリティ・スキルは `js/data_homunculus.js` の表で変更・追加できます。

### 装備（杖・法衣・触媒）

錬金術書『武具錬成論』（A.Lv 5）を読むと【錬装の炉】が建てられ、「装備」タブが現れます。

| 系統 | 段階 | 効果 |
| --- | --- | --- |
| 杖 | I〜VII（I〜III 本編 / IV〜VII クリア後） | 魔法の与ダメージ +10%〜+180% |
| 法衣 | I〜VII（同上） | 最大HP +30〜+360、被ダメージ -5%〜-34% |
| 触媒（8系統） | I〜III（I 本編 / II〜III クリア後） | 特定魔法の威力、MP回復、再使用時間、最大HP・回復量など |

上位の段階は1つ下の段階の装備を素材に使います。段階は `js/data_equip.js` の表に行を足すだけで増やせます。

### クリア後のやり込み要素

物語を終えると、書庫に新しい書物が現れます。読むとそれぞれ解放されます（「装備」タブも追加されます）。

| 要素 | 解放する書物 | 内容 |
| --- | --- | --- |
| **装備の上位段階** | 『深淵の武具』『至高の武具』『原初の武具』（錬金術書） | 杖・法衣の IV〜VII 段階と触媒の II〜III 段階。主の素材・深層の素材・【主の魂晶】（ランク5以上の主）・【深淵の核】（深層20層以降）を使います |
| **物質変換** | 『変成の祭壇』（錬金術書） | 賢者の石を破砕の臼で砕いて「欠片」にし、【変成の祭壇】で魔素と合わせて採取素材を生み出します。採取素材の完全自動化が可能に。深層の素材とボス素材は変換できません |
| **冥界の深層** | 『深淵考』（魔術書） | 階段で下へ降り続ける階層ダンジョン。深いほど敵が強く（HP +30%/層）、深層でしか採れない素材があります。5層ごとの道標から潜り直せます |
| **強化ボスへの再戦** | 『討伐録』（魔術書） | 各地の主（5体）に何度でも挑めます。倒すたびにランクが上がり、HP +50%・攻撃力 +15%、報酬は3ランクごとに増えます |

### 探索中の操作

| キー | 動作 |
| --- | --- |
| W A S D / 矢印 | 移動 |
| マウス | 照準 |
| 1〜6 | 魔法を放つ |
| 左クリック(長押し) | 最後に使った魔法を連射 |
| E | 採取 / 帰還ゲートで工房へ戻る |
| H | 帰還の詠唱(基本3秒、技能【帰還術】で短縮。動く・被弾で中断) |
| Q / R | 回復薬 / 魔力薬 |
| Esc | 一時停止 |

力尽きると**採取袋の素材を全て失って**工房に戻されます。

```
alchemy-game/
├── index.html      画面の骨組み
├── assets/
│   ├── manifest.js 使う画像ファイルの一覧（画像を追加したらここに書く）
│   └── README.md   画像の命名規則・推奨サイズ・ID一覧
├── style.css       見た目
├── js/
│   ├── assets.js   画像の読み込みと描画(画像が無ければ図形で代用)
│   ├── data.js     ★アイテム・レシピ・書物・技能・魔法・敵・フィールド・物語の定義
│   ├── data_post.js ★クリア後要素(物質変換・深層・強化ボス)の定義
│   ├── data_equip.js ★装備(杖・法衣・触媒)の段階表
│   ├── data_homunculus.js ★ホムンクルスの種類・培養レシピ
│   ├── state.js    セーブデータ、レベル、技能、生産処理などのルール

│   └── main.js     起動処理とメインループ
└── tests/
    └── validate.js データの整合性チェック
```

### 調整・拡張のしかた

ほとんどの調整は **`js/data.js` を書き換えるだけ** でできます。

- レシピの所要時間を変える → `RECIPES` の `t`(秒)
- 新しいアイテムを追加 → `ITEMS` に1行追加し、`RECIPES` か `FIELDS` の `nodes` で入手方法を作る
- 書物の文章を変える → `BOOKS` の `text`
- 物語(序章・結末) → `STORY`

変更したら、次のコマンドで「存在しないアイテムを参照していないか」
「賢者の石まで到達できるか」を確認できます(Node.js が必要)。

```bash
node alchemy-game/tests/validate.js
```

### 画像素材

ドット絵とスプライトシートによるアニメーションに対応しています。`assets/README.md` を参照してください。
画像を置いて `assets/manifest.js` に書き足すだけで、該当する図形アイコンが画像に置き換わります。

### 開発者パネル(バランス調整用)

`index.html?debug` のように URL の末尾に `?debug` を付けて開くと、画面右に
「M.Lv+1」「全素材+20」「生産速度×10/×100」などのボタンが表示されます。
通しプレイをせずに終盤の確認をしたいときに使ってください。
画面右と「記録」タブには**プレイ時間**が表示されるので、テストプレイ時の目安にできます。
