# シナリオ執筆ガイド（VN会話劇）

『鋼鉄戦線』のストーリーは、各章の **開幕（intro）** と **終幕（outro）** で再生される
**VN（ビジュアルノベル）風の会話劇** です。立ち絵＋名前プレート＋台詞ボックスで、
複数キャラが順に喋り、表情・立ち位置・演出を指定できます。

データは全て **`js/data.js`** に集約しています。台本を書く／渡すだけでOKです。

---

## 1. 原稿の渡し方（自由形式でOK）

台本は**普通の脚本の形**で書いてくれれば、こちらが下記のビート配列に整形して流し込みます。
例：

```
【第一章 開幕】

ナレーション：辺境採掘基地カストル。最後の通信から、72時間。
指揮AI：……システム再起動。防衛権限を掌握した。
オペレーター（驚き）：指揮官、周辺に多数の反応――生体ではありません！  ＜画面を揺らす＞
指揮AI：数で来るなら、数で返す。防衛開始だ。
```

- 「キャラ名：台詞」の形式で行を並べるだけでOK。
- 括弧で **表情**（驚き・笑顔 等）、`＜＞`で **演出**（揺らす・フラッシュ 等）を書き添えてくれれば反映します。
- 地の文は「ナレーション：」または話者なしで。
- 章ごとに「開幕／終幕」を分けてください。

---

## 2. 登場人物（`G.CHARACTERS`）

`js/data.js` 内の `G.CHARACTERS` がキャラ登録簿です。自由に追加・改名できます。

```js
G.CHARACTERS = {
  narration: { name: '', color: '#cdd8e6', side: 'center' },        // 地の文（消さないで）
  ai:    { name: '指揮AI',       color: '#37d0ff', side: 'left',  icon: '🛰', img: {} },
  op:    { name: 'オペレーター', color: '#ffd24a', side: 'right', icon: '🎧', img: {} },
  swarm: { name: '？？？',       color: '#ff5d6c', side: 'right', icon: '☣', img: {} },
};
```

| フィールド | 意味 |
|-----------|------|
| `name`  | 名前プレートに出る表示名 |
| `color` | 名前の色（テーマカラー） |
| `side`  | 既定の立ち位置 `left` / `right` / `center`（center=立ち絵なし） |
| `icon`  | 立ち絵PNG未配置時のプレースホルダ用の絵文字 |
| `img`   | 表情ごとの立ち絵PNGパス（`portraits/` に置く。下記参照） |

### 立ち絵PNGの割り当て
画像は `portraits/` に置き、`img` に表情名→パスでマッピングします（仕様は `portraits/README.md`）。

```js
ai: {
  name: '指揮AI', color: '#37d0ff', side: 'left', icon: '🛰',
  img: { neutral: 'portraits/ai.png', alert: 'portraits/ai_alert.png' },
},
```

PNG未配置の間は自動でプレースホルダ表示になるので、**台本だけ先に進められます**。

---

## 3. ビート（台詞1行）の書式

`intro` / `outro` は次の2形式どちらでも取れます。

- **文字列** … 地の文として表示（空行で段落＝ページ送り）。手軽。
- **ビート配列** … 立ち絵つきの会話劇。表現力が高い。

ビート1個＝台詞1行のオブジェクト：

```js
{ who: 'op', expr: 'alert', pos: 'right', fx: 'shake', text: '基地を全周から囲んでいます！' }
```

| キー | 必須 | 説明 |
|------|------|------|
| `who`  | 〇 | 話者のキャラID（`G.CHARACTERS` のキー）。`narration` で地の文 |
| `text` | △ | 台詞。省略すると「演出だけのビート」になり自動で次へ進む |
| `expr` |   | 表情名（`img` のキー。例 `neutral` / `alert`）。立ち絵を差し替える |
| `pos`  |   | この台詞での立ち位置 `left` / `right`（省略時はキャラの `side`） |
| `fx`   |   | 画面演出：`shake`（揺れ）/ `flash`（発光）|
| `flashColor` | | `fx:'flash'` の色（例 `'rgba(255,40,40,.6)'`）|
| `bg`   |   | 背景の差し替え（CSSの background 値。例 `'radial-gradient(...)'`）|
| `cutin`|   | バナー型カットイン：`{ jp:'警告', en:'ALERT', cls:'boss', dur:2000 }` |

### 演出だけのビート（text省略）
場面転換・効果だけ入れたい時は `text` を省略すると、約0.36秒後に自動で次のビートへ進みます。

```js
{ bg: 'radial-gradient(120% 120% at 50% 30%, #2a0d12, #06080e 78%)' },
{ fx: 'flash', flashColor: 'rgba(255,40,40,.55)' },
{ who: 'swarm', expr: 'neutral', text: '……喰ラウ……' },
```

## 4. 完成サンプル（第一章 開幕）

```js
intro: [
  { who: 'narration', text: '辺境採掘基地カストル。最後の通信から、72時間。' },
  { who: 'ai', text: '……システム再起動。〈指揮AI〉、起動。基地の防衛権限を掌握した。' },
  { who: 'op', expr: 'neutral', text: '指揮官、お目覚めですか。周辺に多数の反応――生体ではありません。' },
  { who: 'op', expr: 'alert', fx: 'shake', text: 'これは……機械の群れ。基地を全周から囲んでいます！' },
  { who: 'ai', text: '数で来るなら、こちらも数で返す。工業ラインを起こせ。' },
  { who: 'narration', text: '鉱区に採取モジュールを送り、素材を中間素材に。\n3つの部品を組み上げれば、量産機が際限なく流れ出す。' },
  { who: 'ai', expr: 'alert', text: '量産で押し返す。――防衛開始だ。' },
],
```

## 5. 再生のされ方・操作

- **開幕** … 章カットイン（章番号＋脅威キャラ）→ そのまま会話劇へ。
- **終幕** … 会話劇 → 章の「決断（choice）」モーダルへ。
- プレイヤー操作：**クリック/タップで送り**（タイプ中なら一気に全文表示）、右上 **スキップ** で会話を即終了。

---

## 6. まとめ：あなたの作業

1. **台本を書く**（第2節の自由形式でOK。表情・演出は括弧で添えるだけ）。
2. （任意）**立ち絵PNG**を用意して `portraits/` に置く。
3. こちらに渡す → ビート配列へ整形し、`data.js` の各章 `intro`/`outro` に流し込み、
   キャラ登録と画像パスを設定します。

台本だけでも、立ち絵だけでも、片方ずつ進められます。お気軽にどうぞ。
