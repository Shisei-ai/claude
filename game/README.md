# 鋼鉄戦線 — Steel Front

工業力で量産ロボットを生み出し、物量で押し寄せる機械生命体「群体（スウォーム）」の侵攻を防ぐ、
シナリオ付きのブラウザ防衛ストラテジー。ビルド不要・依存なしの素のHTML/CSS/JSで動きます。

## 遊び方

`game/index.html` をブラウザで開くだけ。（ローカルサーバ不要。ダブルクリックでも動作します）

### 基本ループ
1. **工業を立ち上げる** … 発電所で電力を供給し、採掘機で鉱石を掘り、製造工場でユニットを建造。
2. **編成を整える** … 来る波の構成を読み、相性の良いユニットを建造キューに積む。
3. **「次の波を呼ぶ」** … 準備が整ったら出撃。ユニットは自動で前線へ進軍し、群体を迎撃する。
4. **資源を増やし、研究で強化** … 撃破報酬と生産で経済を回し、研究ツリーで新ユニット・強化を解放。
5. **章を勝ち抜く** … 章クリアごとにシナリオが進み、恒久ボーナスを選ぶ決断を迫られる。

> 準備フェーズに時間制限はありません。じっくり経済を育ててから出撃するのが安全策。
> ただし慎重すぎても話は進みません。攻めどきはあなた次第。

## 絡み合うシステム（奥深さの源）

- **電力（フロー資源）** … 供給より消費が大きいと全生産効率が低下。発電と拡張のバランスが要。
- **指揮容量** … 同時展開できるユニット総量の上限。通信中継塔や研究で拡張。
- **3すくみ** … 軽兵 → 射撃 → 重装 → 軽兵。敵波の構成に合わせた編成が勝敗を分ける。
- **研究ツリーの分岐** … 工業／軍事／特殊の3系統。どこに伸ばすかで戦略が変わる。
- **シナリオの選択** … 章の合間の決断が、経済・軍事・指揮の恒久ボーナスとして残り続ける。

## ユニットと相性

| 系統 | ユニット | 役割 |
|------|----------|------|
| 軽 | 軽兵ロボ / 歩兵ロボ / 自爆ドローン | 安価な物量・主力・対密集 |
| 重 | 重装ロボ | 頑強な壁役。軽兵に強い |
| 射 | 射撃ロボ | 遠距離火力。重装に強いが脆い |
| 支 | 工兵ロボ | 味方と砲台を継続修理 |

有利な相性で攻撃すると与ダメージ ×1.6、不利だと ×0.65。

## ファイル構成

```
game/
├─ index.html        画面構造
├─ css/style.css     スタイル（SFダークトーン）
└─ js/
   ├─ data.js        建物・ユニット・敵・研究・シナリオの全データ（バランス調整はここ）
   ├─ game.js        状態管理・経済・自動戦闘・波・研究のコアロジック
   └─ ui.js          描画（Canvas）・入力・モーダル・メインループ
```

数値バランスはすべて `data.js` に集約しているので、調整や拡張が容易です。

## シナリオ（あらすじ）

辺境採掘基地カストルの通信途絶から72時間。目覚めた指揮AI〈あなた〉は、
自己増殖する機械の群れと対峙する。その正体は、旧文明が遺した暴走する無人兵器工場だった——。
全4章。地下の中枢炉を巡る最終防衛戦の先に、次なる戦線の予兆が待つ。
